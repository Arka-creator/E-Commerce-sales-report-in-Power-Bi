# E-commerce Sales Report (EXP-1)

This project contains a Power BI dashboard for analyzing e-commerce sales data.  
It provides insights into sales performance, profit distribution, and customer trends.

## Features
- **Main Metrics**: Quantity, Amount, Net Sales, Profit
- **Category Analysis**: Sales and profit by product category
- **Customer Insights**: Amount by customer name
- **Regional Insights**: Profit by state
- **Quarterly Filters**: View performance by Q1, Q2, Q3, Q4

## Tools & Technologies
- Microsoft Power BI Desktop
- DAX (Data Analysis Expressions)
- SQL database (Orders, Customers, Products, Payments, OrderDetails)
